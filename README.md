# Cuphead Mobile Optimization & Controller Setup

This repository provides setup guides, controller profiles, and device compatibility matrices for running the Cuphead Android port smoothly across various mobile chipsets.

## Supported Architectures
- **ARM64 (arm64-v8a)** — Recommended for modern devices running Android 10+
- **ARMv7 (armeabi-v7a)** — Legacy support for older devices (32-bit)

## Included Assets
- `/configs/controller-mappings.json`: Pre-configured controller bindings for Xbox, DualShock, and Bluetooth telescopic controllers.
- `/configs/touchscreen-presets.cfg`: Ergonomic touch button placements for screens under 6.7 inches.

## Troubleshooting Common Errors
- **"App Not Installed" (Package Parsing Error):** Check if your storage permissions are enabled or if an older signature conflict exists.
- **Frame Drops & Audio Stutter:** Lower the particle detail in settings or configure custom frame pacing.
